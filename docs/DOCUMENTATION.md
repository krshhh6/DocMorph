## 1. Introduction

The goal of this project is to build a practical Python tool that can check if an image is a real camera photo or generated by AI tools like Midjourney, DALL-E 3, or Stable Diffusion.

When testing normal AI detector models from the internet, I found a big problem: almost all of them give wrong results on normal photos sent over WhatsApp or Instagram. WhatsApp compresses a 5 MB phone photo down to 50 KB, and the AI model thinks the compression blur is actually an AI generation artifact.

To fix this, I made a script that does not just depend on a single model. It combines simple metadata checks, file byte inspection, camera lens physics, and a Vision Transformer model together to give an accurate and explainable answer.

## 2. Libraries Used

I used five main Python libraries for this project:

- **torch (PyTorch):** Used to run the neural network. It automatically uses hardware acceleration through CUDA so the scan takes less than a second.
- **transformers:** Used to load the pre-trained Vision Transformer model (`dima806/ai_vs_real_image_detection`) from Hugging Face without needing to write model layers from scratch.
- **PIL (Pillow):** Opens the image files and extracts camera EXIF tags like camera brand and model name.
- **cv2 (OpenCV):** Used to find image edges using Canny edge detection so we can measure color fringing.
- **numpy:** Used for basic array operations and calculating standard deviations of color channels.

## 3. How the 4 Forensic Checks Work

Instead of guessing, the program runs four practical checks on the file:

### Check 1: Camera Hardware & EXIF Data
The script check for camera EXIF tags first. Real cameras from phones like Samsung, iPhone, Pixel, OnePlus, or DSLRs save the camera model, aperture, shutter speed, and ISO inside the file. AI generators do not have a physical camera sensor, so their files either have empty metadata or say things like "DALL-E".

### Check 2: AI Watermarks and Provenance Tags
Companies like OpenAI and Google add digital markers to their AI images (like C2PA content credentials or SynthID). The script opens the image file in binary read mode and scans the raw bytes for markers like `dall-e`, `c2pa`, `synthid`, and `midjourney`. If found, we know immediately it is AI.

### Check 3: Handling WhatsApp and Social Media Compression
When testing an WhatsApp image, the file size is usually very small (under 400 KB) and metadata is removed by WhatsApp servers. Instead of failing, the detector checks if the file is small and still has real lens physics before deciding.

### Check 4: Glass Lens Dispersion (Optical Physics)
Physical camera lenses are made of curved glass. When real light enters glass, red light and blue light bend at slightly different angles. This causes a tiny, natural color spread along sharp edges called chromatic aberration.

In OpenCV, I extract the edges and calculate the difference between the Red and Blue channels. This allow the detector to differentiate between real camera glass and AI pictures. AI images are drawn by math in latent space, so their edges are completely flat with no glass dispersion.

## 4. The Neural Network Model

For the deep learning part, I used:
- **Model:** `dima806/ai_vs_real_image_detection` (hosted on Hugging Face)
- **Type:** Vision Transformer (ViT)

I picked a Vision Transformer over older CNNs (like ResNet) because a ViT splits the picture into 16x16 square patches and uses self-attention. This lets the model compare lighting and textures across the whole image at once, which is great at catching unnatural AI lighting.

---

## 5. Decision Rules

The code uses simple logic to combine all checks:

1. **If AI tags are found in bytes:** Verdict is AI Generated (99.8% risk).
2. **If real camera make/model is found in EXIF:** Verdict is Real Photograph (risk dropped below 12%).
3. **If it is a small WhatsApp file but has real lens dispersion:** Verdict is Real Photograph (Social Media).
4. **If none of the above match:** It uses the Vision Transformer prediction score directly.
